# Die Modelle sind exakt festgenagelt, nicht mit >=. Grund: Bei Forschungs-
# frage 1 sind die Voreinstellungen dieser beiden Bibliotheken der
# Untersuchungsgegenstand. Mit einer anderen Version kommen andere Zahlen
# heraus und die Messungen von zwei Rechnern sind nicht mehr vergleichbar.
#
# Es sind genau die Versionen, unter denen die Messungen entstanden sind.
# Nachgeprueft auf zwei Rechnern (Colab mit Python 3.13, Windows mit 3.12),
# Datensatz S5E3, fuenf Folds:
#
#   Random Forest   identisch unter 1.6.1 und 1.7.2, bis zur letzten Stelle
#                   und in jedem einzelnen Fold. Die Voreinstellungen der
#                   beiden Versionen unterscheiden sich in keinem Parameter.
#   XGBoost         AUC 0.866285 unter 3.4.1, 0.863911 unter 3.0.5. Die
#                   Voreinstellungen unterscheiden sich nur in
#                   enable_categorical, und das bleibt hier wirkungslos, weil
#                   der ColumnTransformer ein numpy-Array liefert. Der
#                   Unterschied steckt also im Algorithmus selbst.
#
# Wer diese Zahlen aendert, macht die vorhandenen xgb-Messungen ungueltig.
